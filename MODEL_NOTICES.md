# Embedding Model Attribution

This package includes the ONNX model and tokenizer from [Qdrant bge small en v1.5 ONNX](https://huggingface.co/Qdrant/bge-small-en-v1.5-onnx-Q/tree/aa8f8b060edb00e03bfdd08813a2949946c8ba55), revision `aa8f8b060edb00e03bfdd08813a2949946c8ba55`. It derives from [BAAI bge small en v1.5](https://huggingface.co/BAAI/bge-small-en-v1.5). The ONNX repository identifies its license as MIT and records the revision as a change to match the upstream MIT license.

The model file SHA-256 is `51f1bd0addd6e859e42c2c8021a5e5461385bb676a649f4b269aa445449f2431`. The exact model and tokenizer files, pooling behavior and normalization are reused through FastEmbed. The package does not infer numeric precision from the repository name.
